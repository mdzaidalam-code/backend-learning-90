# 🚀 90-Day Backend Engineering Mastery (`backend-mastery-90`)

An intensive, hands-on journey to mastering production-ready backend engineering, REST API architecture, web security, and database design using Node.js and Express.

---

## 🛠️ Tech Stack

* **Runtime:** Node.js
* **Framework:** Express.js
* **Environment Management:** `dotenv`
* **Development Server:** `nodemon`
* **Version Control:** Git & GitHub

---

## 📁 Repository Structure

```text
